# 北京华誉字节科技有限公司官网

> 承岐黄之术 · 护百姓健康

中医风格暖黄色调的企业官网，介绍华誉字节科技、名医 IP 运营矩阵（医生界面）与北京劲松中西医结合医院三大业务。

## 在线访问

https://heshumei-bee.github.io/huayu-byte-website/

## 技术栈

- 纯 HTML + CSS + JavaScript，无构建依赖
- 响应式布局，适配电脑与手机
- 本地预览：双击 `index.html` 或 `python -m http.server 8899`

## 目录结构

```
├── index.html      # 单页官网
├── css/style.css   # 中医暖黄色设计系统
├── js/main.js      # 交互脚本
└── assets/
    ├── img/        # 门店实景、医生界面截图、视频海报
    └── video/      # 创始人访谈、品牌宣传片
```
